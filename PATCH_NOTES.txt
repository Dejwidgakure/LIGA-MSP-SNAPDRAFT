ZASADY OPISANE NA PODSTAWIE AKTUALNEGO POKER DRAFTU:

- Custom Packi są w aktualnym programie wyłączone dla Poker Draftu

=========================================================
PATCH102 COMPATIBILITY OVERRIDE — FINAL
=========================================================
This cumulative Kroniki package is now aligned to MSP SnapDraft PATCH102 / Data Contract V2 Archive Freeze.

- draftConfigV2 is the only archive configuration source.
- no top-level draft.mode / draft.bans / draft.presetCard fallbacks remain in runtime consumers.
- draft-stats-engine.js and Hall of Fame resolve the mode from draftConfigV2.
- the Draft page exposes exactly three player-facing families:
  Tryb Draftowania / Rozszerzenia / Ustawienia Specjalne.
- Bans, Lucky Cards, Preset Card and Twist are rendered as historical detail payloads below the families.
- Kroniki do not display Timer seconds or the exact extra-buffer runtime value.
- old packBuffer archive logic is replaced by additionalPackBuffer.
- Archive 10 reads ban history from specialSettings.poolRules.bans.cards.
- database.js is intentionally NOT included. Install PATCH102 first.
